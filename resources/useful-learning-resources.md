# Curated Resources

This is a curated list of resources I use or recommend for Git, data analytics, and data science. It reflects what has been most useful in my own work and learning.

## Git and GitHub

- [Git Documentation](https://git-scm.com/doc)
- [GitHub Docs](https://docs.github.com)
- [Pro Git Book (free)](https://git-scm.com/book/en/v2)
- [GitHub Skills (interactive courses)](https://skills.github.com)

- [Kaggle Learn](https://www.kaggle.com/learn)
- [DataCamp](https://www.datacamp.com)

- [pandas Documentation](https://pandas.pydata.org/docs/)

- [Tableau Learning](https://www.tableau.com/learn)
- [Storytelling with Data (book)](https://www.storytellingwithdata.com)
